# Power BI

Place your built `.pbix` file in this folder (e.g. `clinic_efficiency_dashboard.pbix`).

- `data_model/` — the 4 fact/dimension CSVs to import (see `docs/power_bi_data_model.md` for the relationships to build)
- Measure formulas: `docs/power_bi_dax_measures.md`
- Full 3-page layout spec: `docs/power_bi_dashboard_spec.md`
